Install in 3 steps

One installer does everything — registry, panel, and its own Python. No admin rights.

1

Download & extract

Hit the download button and extract the ZIP anywhere you like.

2

Double-click install.bat

Registers the panel and sets up a self-contained Python environment. Got an NVIDIA GPU? It offers CUDA acceleration too.

3

Restart After Effects

Open it from Window > Extensions > Whisper Captions. The first transcription downloads your chosen model (once).

💡

No Python on your machine? Run winget install astral-sh.uv once, then install.bat again — it handles the rest.

How it works

🎙️

Select & transcribe

Select the audio/video layer in your comp, pick a model & language (or auto-detect) and hit Transcribe. Everything runs on your machine.

→
✂️

Smart splitting

Set max characters per line and 1–3 lines. Long sentences split at natural boundaries, and a live preview shows exactly how captions will sit in your comp.

→
✨

One keyframed layer

A single "Captions" text layer with Source Text keyframes — bottom-centered, drop-shadowed, and trivially easy to restyle.
