Install in 4 steps

The installer handles everything — panel, registry, Everything setup. For real.

1

Download & extract

Grab the latest release and extract the ZIP anywhere.

2

Run install.bat as admin

Right-click → Run as administrator. It installs the panel, enables it, and sets up Everything for you.

3

Restart After Effects

Open it from Window > Extensions > Missing Files Finder.

4

Scan & relink

Select your missing items, hit SCAN, then RELINK ALL. That's the whole job.

💡

The magic is Everything by voidtools — a free tool that indexes your whole machine and finds any file in milliseconds. The installer downloads and configures it automatically (or uses your existing copy).

Why it slaps

⚡

Millisecond search

Powered by Everything's index of your whole machine — no folder guessing, no "search subfolders" coffee breaks.

🔗

Relink All

Every uniquely-matched file relinks in one click. Multiple candidates? Pick from a list, done.

🎨

PSD layer-aware

Relinking a PSD normally nukes your layer references. This panel preserves them (via AutoHotkey automation).

📦

Copy on relink

Optionally copy found files into your project folder while relinking — consolidate as you fix.

🖤

Native dark UI

Sits in After Effects like it was born there — same pink-purple family as TikTalk and Bin Sorter.

🆓

Free, forever

Open source. Finding your own files shouldn't be a subscription.

Requirements

  • ✓ Windows — macOS not supported (Everything is Windows-only)
  • ✓ After Effects CC 2018 (v15) or newer
  • ✓ Everything by voidtools — free; the installer sets it up automatically
  • ✓ AutoHotkey v2 — optional, only for PSD layer relinking
