Install in 4 steps

No certificates, no ZXP wrestling. Windows shown — Mac steps below.

1

Download & extract

Hit the download button and extract the ZIP anywhere you like.

2

Double-click Install.bat

It copies the panel and enables it for your user — done in seconds.

3

Restart Premiere Pro

Open it from Window > Extensions > Mr. Bin.

4

Let him work

Tweak the destination bin names if you like, then hit SORT. UNDO brings the exact original structure back.

🍎

On a Mac? Extract, then run Install-Mac.command from Terminal (chmod +x it first), restart Premiere and you're set. Manual install paths for both platforms are in the README.

How it works

🔍

Scans your project

Recognizes video, audio, images, PSD/PSB/AI/EPS, MOGRTs, sequences — even missing media.

→
🗂️

Sorts into bins

Every item lands in the right bin. Rename destinations, protect bins you don't want touched, auto-delete emptied ones.

→
↩️

Undo, completely

One click restores the exact original bin structure. Experiment without fear.

Why it slaps

⚡

One-click sort

The whole project panel organized by media type in a single click — or sort just one selected bin.

↩️

Full undo

Not a "best effort" undo — the exact original structure comes back, every item where it was.

🧠

Smart detection

mp4, mov, mxf, R3D, BRAW, wav, aiff, exr, dpx, psd, ai, mogrt, sequences and more — each type knows its home.

✏️

Your names, your rules

Rename every destination bin, keep a protected list of bins to ignore, optionally delete bins that end up empty.

⌨️

Keyboard friendly

Ctrl/Cmd+Enter to sort, Ctrl/Cmd+Z to undo, Ctrl/Cmd+S to save settings.

🆓

Free, forever

Open source under MIT. A tidy project panel shouldn't cost money.
