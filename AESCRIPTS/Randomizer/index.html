RANDOMIZER

chaos, on tap.

A dockable After Effects panel that randomizes position, rotation, scale & opacity on your selected layers — with ranges, add/set modes, and a tidy single-step undo when the chaos goes too far.

Install in 4 steps

One PowerShell script does the whole job — no certificates, no ZXP wrestling.

1

Download the release

Grab Randomizer-v1.0.0.zxp and install.ps1 from the latest release, into the same folder.

2

Run install.ps1

Right-click → Run with PowerShell. It extracts the panel and enables it for your user.

3

Restart After Effects

Open it from Window > Extensions > Randomizer — it docks like any native panel.

4

Make some chaos

Select layers, set your ranges, hit Randomize All. Too spicy? One Ctrl+Z undoes everything.

💡

Prefer a GUI? The .zxp installs with any ZXP installer (Anastasiy's Extension Manager, aescripts ZXP Installer) — that route works on Mac too. Manual install steps are in the README.

How it works

🎛️

Pick your properties

Four cards — Position, Rotation, Scale, Opacity. Toggle off whatever should stay untouched.

→
📏

Set ranges & modes

Add jitters existing values, Set assigns absolutes within your min/max. Per-axis when you need it.

→
🎲

Randomize All

One button, instant entropy across every selected layer — wrapped in a single undo group.

Why it slaps

🎯

Controlled chaos

Min/max ranges per property — randomness that stays exactly inside the bounds you set.

➕

Add or Set modes

Jitter what's already there, or assign fresh absolute values. Scale even has a Multiply mode.

🧊

3D aware

2D layers rotate on Z; 3D layers get independent X/Y/Z rotation and per-axis position offsets.

↩️

One-step undo

Every randomize wraps in a single undo group — a hundred layers revert with one Ctrl+Z.

🖤

Native dark UI

Dockable CEP panel in the same pink-purple family as TikTalk, Mr. Bin and Missing Files Finder.

🆓

Free, forever

Open source. Entropy wants to be free.
