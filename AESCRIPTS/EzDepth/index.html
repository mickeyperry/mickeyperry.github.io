Install in 3 steps

One installer does everything — registry, panel, and its own Python.

1

Download & extract

Hit the download button and extract the ZIP anywhere you like.

2

Double-click install.bat

Registers the panel and sets up a self-contained Python environment. NVIDIA GPU detected? It installs the CUDA build automatically.

3

Restart After Effects

Open it from Window > Extensions > EzDepth. The first click downloads the model (once).

💡

No Python on your machine? Run winget install astral-sh.uv once, then install.bat again — it handles the rest.

How it works

🎯

Park the playhead

Move to the frame you want a depth map for, in any comp.

→
🧠

Generate Depth

Depth Anything V2 runs locally on your GPU (or CPU) — well under a second once it's warm.

→
👻

Guide layer drops in

A grayscale depth layer appears above everything — visible while you work, invisible in the final render.

Why it's useful

🖼️

Current frame, one click

No exporting, no round-tripping through another app — capture, infer and import without leaving the comp.

🌓

Near = white, out of the box

Grayscale output in the same convention AE's own depth-based effects expect — Camera Lens Blur, Turbulent Displace, Depth Matte.

👻

Guide layer, not clutter

Sits above everything for reference while you work, and is automatically skipped when you render.

🔁

Refresh in place

Generate again on a new frame and the previous depth layer for that comp is replaced, not stacked.

⚡

GPU accelerated

NVIDIA GPU? Runs on CUDA, well under a second per frame. No GPU? Falls back to CPU automatically.

🔒

100% local

Depth Anything V2 runs entirely on your machine. No cloud, no account, no per-image fees.

Requirements

  • ✓ Windows 10 / 11
  • ✓ After Effects 2022 (22.0) or newer
  • ✓ Python or uv — the installer sets up its own environment
  • ✓ NVIDIA GPU recommended — CPU works too, just noticeably slower
  • ✓ ~3 GB disk for PyTorch, ~100 MB for the model — downloaded once, on install / first use
